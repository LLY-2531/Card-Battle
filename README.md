# 卡牌爬塔 Card Battle

> 一个跑在命令行里的 **肉鸽卡牌战斗** 小游戏。
> 抽牌、算能量、看敌人意图、一层层往上打——没有图形界面，全靠控制台。

## 简介

项目把「卡牌爬塔」拆成四层：

- **模型层（`model/`）**：玩家、敌人、卡牌、Buff、技能、存档、排行榜，全是纯粹的 POJO，只管存数据。
- **服务层（`service/`）**：战斗结算、抽牌、敌人意图、存档读写、排行榜排序、音效播放，所有规则都在这里。
- **视图层（`view/`）**：`ConsoleView` 负责菜单、战斗界面、延迟打印和 ANSI 彩色输出。
- **架构层（`jiagou/`）+ 全局层（`core/`）**：`Main` 是入口，`Global` 是全局状态容器（玩家、卡池、当前敌人、层数、回合）。

**五行代码就能跑起来**：`javac` 编译，`java jiagou.Main` 启动，不用装任何第三方库。

## 玩法一览

| 环节 | 说明 |
|---|---|
| 🃏 抽牌 | 每回合从 22 张永久卡池里随机抽 5 张不重复的牌 |
| ✋ 选牌 | 从 5 张里挑 **3 张**，按空格分隔输入编号 |
| ⚡ 能量 | 每回合能量回满，每张牌有各自的能耗，能量不够打不出去 |
| ⚔️ 先手 | 比较玩家与敌人的**速度**，快的先动手 |
| 👁 意图 | 开打前先告诉你敌人这回合要放什么技能、预计多少伤害 |
| 🛡 护甲 | 护甲先扣，护甲破了才掉血；「穿刺」无视护甲 |
| 🎁 奖励 | 每层通关三选一 Buff：加血上限、加速度、加护甲 |
| 🏆 排行榜 | 得分 = 层数 × 100 + 剩余血量，只留前 10 名（同名保留最高分） |
| 💾 存档 | 战斗中可以存档退出，下次从同一层接着打 |

## 架构

```
Main（jiagou）
   │
   ├─ SettingsService   读 config/settings.txt → Global.settings
   ├─ EnemyService      填充 5 层敌人模板 + 技能池
   ├─ CardService       填充 22 张永久卡
   ├─ BuffService       填充 5 个开局 Buff
   └─ SoundService      循环播 music/bgm.wav
   │
   ▼
ConsoleView.menuView()  ← 主菜单（1 新游戏 / 2 读档 / 3 排行榜 / 4 设置 / 5 团队 / 6 退出）
   │
   ▼
battleView()  ── 每回合 ──→ 能量回满 → 抽 5 张 → 选 3 张
                              │
                              ├─ 速度判定先手
                              ├─ playerTurnPhase()  逐张结算伤害 / 护甲 / 吸血 / 自伤
                              ├─ enemyTurnPhase()   敌人意图伤害 × 攻击加成 → 扣护甲 → 扣血
                              └─ 结算 → 胜利进 rewardView() / 失败写排行榜
```

所有跨模块共享的状态都放在 `core.Global` 里（玩家、卡池、当前敌人、层数、回合、设置），服务层只做计算，视图层只做输入输出。

## 快速开始

需要 **JDK 17**（`java -version` 能输出版本即可），无第三方依赖。

### 命令行

```bash
# 1. 拉源码
git clone https://github.com/LLY-2531/Card-Battle.git
cd Card-Battle

# 2. 编译到 out/
javac -encoding UTF-8 -d out $(find src -name "*.java")

# 3. 启动（必须在项目根目录运行，程序用相对路径读 music/ sound/ config/）
java -cp out jiagou.Main
```

Windows 上也可以直接双击 `run.bat`，它会自动编译并启动。

### IntelliJ IDEA

1. `File → Open` 选中项目根目录（识别 `game.iml`）；
2. 确认 SDK 为 JDK 17；
3. 右键 `src/jiagou/Main.java → Run`。

> 注意：工作目录必须是项目根目录，否则读不到 `music/bgm.wav` 和 `config/settings.txt`（这两处失败会静默跳过，游戏仍可运行，但没有音乐）。

| 层 | 敌人 | 血量 | 攻击加成 | 速度 |

| 1 | 灰狼 | 30 | ×1.0 | 10 |

- **普通敌人技能**：猛击 7 / 重击 11 / 防御姿态（+6 护甲）

## 设计说明

- **不引入任何第三方库**：颜色用 ANSI 转义，音频用 JDK 自带的 `javax.sound.sampled`，文件读写只用 `java.io`。
- **规则与界面分离**：`service/` 里算数值、`view/` 里打印文字，改界面对战斗逻辑零影响。
- **状态集中管理**：全局状态只在 `core/Global` 声明一处，避免各层互相传一堆参数。
- **容错**：音乐/音效/设置/排行榜文件缺失或读不了时静默降级，游戏照常能玩。
